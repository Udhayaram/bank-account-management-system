# Bank Account Management System

## Description

Bank Account Management System is a simple Python project that simulates basic banking operations. The program allows the user to create an account, deposit money, withdraw money, check the account balance, and view account details.

This project was created to practice basic Python programming concepts and understand how these concepts can be used to build a simple real-world application.

## Features

* Create a new bank account
* Enter account holder name
* Enter account number
* Add initial account balance
* Deposit money
* Withdraw money
* Check current balance
* View account details
* Validate user input
* Display error messages for invalid operations
* Exit the program

## How the Program Works

When the program starts, it displays a menu with different banking operations.

The user can select an option from the menu.

For example:

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Balance
5. View Account Details
6. Exit

After selecting an option, the program performs the selected operation and displays the result.

The menu continues to appear until the user selects the Exit option.

## How to Run

Make sure Python is installed on your computer.

Check the Python version:

python --version

Clone the repository:

git clone https://github.com/your-username/bank-account-management-system.git

Open the project folder:

cd bank-account-management-system

Run the Python program:

python bank_account_management.py
